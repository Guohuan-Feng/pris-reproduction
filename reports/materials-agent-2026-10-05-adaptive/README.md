# 材料形成能 Agent：20次有效实验与普通搜索对照

2026-10-05｜导师汇报

**进展：初批7次 + 补充13次 = 20次提供新预测信息的实验。** 首批另有一次已决预测重组不计新信息，一次中断未完成不计；这是分批恢复，不能称为连续无干预20轮。

**数据集：** 已观察的2879条开发材料，2164训练、715适应性验证；训练内部按化学体系两折OOF。目标是形成能（eV/atom），已有30列输入与E04的12列，可选30或42列。[公开数据与在线材料表](https://huggingface.co/datasets/fgh123654/materials-energy-stability-agent-dev)。

**代码流程：** Agent查看误差 → 提出可证伪假设 → 选择一种干预 → 前检去重/阻止已决或未知重跑 → 调用数值模型训练 → 检查反例 → 反思并自动安排下一轮。连续3次完整实验未联合晋级后换干预家族。HGB和ExtraTrees是Agent调用的预测工具。

![材料Agent自循环流程](figures/workflow_zh.png)

**结果：** Agent最低已观察综合误差为 **0.227966611（E011）**，相对旧材料方案 **0.234941540** 降低 **2.969%**。验证MAE为0.215235468，训练OOF MAE为0.240697754；综合分是两者平均，越小越好。

**普通对照：** 最低已观察综合误差0.230324406（H_ADAPT_E004）。本次Agent最低开发误差比普通搜索（含共同历史起点）低1.024%。这仅是本次单次比较。 对照只匹配补充阶段的基础模型拟合上限237，实际使用232、保留余量5；拟合次数不等于CPU时间，初批成本不加入对照上限。

![开发结果与普通搜索比较](figures/results_zh.png)

**结论：** 自循环实验流程已执行并可审计；误差下降不能直接称为Agent独立增益或材料机制发现。没有新独立确认、没有新描述符/DFT，也没有Ehull稳定性专门评价。一次Agent与一个普通搜索种子不能证明普遍优势。
