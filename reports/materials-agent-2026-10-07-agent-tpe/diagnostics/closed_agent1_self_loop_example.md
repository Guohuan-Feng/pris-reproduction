# 一段真实自循环：Agent1 第17—20轮

Agent先读取上一轮保存的反馈和下一问题，再提出配置、执行一次评估、保存反思。这是冻结配方范围内的**配置Agent**，下表来自已闭合的真实实验。2164个形成能训练材料按化学体系分成两折；每轮各折训练Ridge与CatBoost残差，共4次拟合。数值单位均为eV/atom，越低越好。

本组C015是此前搜索的最佳候选（MAE 0.224890290）；固定模型C015是共同基线（同划分MAE 0.232561992），二者不是同一个实验。ΔMAE比较该轮开始时的本组最佳。

**反馈如何改变下一步：**

1. **C017→C018：**提高学习率没有超过旧最佳，含氮/无氧误差及尾部要求失败。下一轮恢复旧最佳的学习率，改问减小趋势正则化是否有效。
2. **C018→C019：**alpha降至30让总体MAE下降0.000238063、含氮偏差减少；但含氮/无氧MAE及尾部条件失败，p99比旧最佳高0.031801110。记录这个取舍后，下一轮从旧控制设alpha300，尝试修复尾部。
3. **C019→C020：**更强趋势正则化改善无氧误差和尾部，但损害含氮/含氧MAE，总体不及C018。下一轮回到C018，尝试降低残差树叶正则化。
4. **C020→STOP：**l2降至3没有超过C018，仅2/6条件通过。保存反思并停止：本组20候选、80/80次拟合已用完。延后的研究问题没有在本组继续执行。

核对实际上下文、保存的下一问题与执行配置：**四轮均一致**。连续尝试会返回当前最佳或旧控制，不能把相邻两轮直接当作单因素对照。四个联合假设均未全部成立；C018按MAE成为本组最佳，也不能据此称化学机理成立或独立泛化已获确认。这里全部是反复查看的训练OOF证据，尚不涉及新测试标签。

**判据范围：**表中6项是该候选在评估前提出的假设诊断，区别于协议固定的10项训练gate和4项新确认晋升条件，不增改后者。按预注册的最小MAE目标更新最佳，允许与联合假设失败同时发生。C018相对固定共同基线的MAE下降约3.40%，p99却上升约7.21%；这些聚合数也不能说明所有尾部材料都变差。
