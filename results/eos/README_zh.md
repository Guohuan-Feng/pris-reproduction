# 独立 E4 状态方程再分析

[English](README.md) | [简体中文](README_zh.md)

**从已发布的能量—体积数值重新拟合了全部 260 个公开体模量结果。** 未运行 VASP。独立优化器与作者体模量的最大绝对差为 **0.00023253 GPa**，绝对差中位数为 **0.0000000509 GPa**，最大相对差为 **0.00009615%**。

1,300 条 stage-B 输入记录中，1,296 条为 complete，1 条为 unconverged，3 条为 failed。沿用来源数据的纳入规则后保留 1,297 个 E(V) 点，得到 257 次五点拟合和 3 次四点拟合。所有已发布候选均纳入再分析。

| 指标 | 复算结果 |
|---|---:|
| 已拟合候选数 | 260 |
| priority / retained-control / screened | 140 / 60 / 60 |
| 体模量中位数 | 374.47091 GPa |
| 最大体模量 | 418.54561 GPa |
| UMA 与 DFT 的 Pearson 相关系数 | 0.769259 |
| UMA 与 DFT 的 Spearman 相关系数 | 0.710143 |
| DFT/UMA 体模量比值中位数 | 0.93954685 |
| 对应的映射 DFT 阈值 | 375.81874 GPa |
| 超过映射阈值：retained / screened | 123 / 1 |
| 对超过映射阈值候选的保留率 | 99.19355% |
| priority 对 screened 的成对排序准确率 | 0.966190 |

在已公开的逐候选数据中，**两个**候选达到原始 400 GPa 阈值；独立拟合也保留这两个结果：

| 候选 | 化学式 | 角色 | 重新拟合的体模量 |
|---|---|---|---:|
| candidate_0017 | Os | priority | 400.38451 GPa |
| candidate_0980 | Re2IrOs6 | screened | 418.54561 GPa |

因此，已发布数值支持的是一个 **priority** 候选超过 400 GPa，而不是整个已选择集合只有一个候选超过 400 GPa。体模量最高的候选被筛除了。这与仓库 `dft/RESULTS.md` 中一个 priority 和一个 screened 候选超过阈值的结果一致；论文正文关于一个候选超过 400 GPa 的表述不应作为整个集合的计数照搬。

映射阈值是在比较 DFT 与 UMA 数值尺度之后计算的，与原始 400 GPa 设计目标不同。此外，这 260 个候选有意过采样了 UMA 预测值较高的结构，其保留率不能独立证明对完整 1,081 个生成候选集合实现了 67.3% 的减少。

`per_candidate.csv` 包含每次重新拟合的结果、作者参考值、绝对与相对误差、状态方程残差及角色。`energy_volume_points.csv` 包含实际纳入的精确数值输入。`summary.json` 记录全部计数、排除任务、依赖版本和 SHA256 哈希。在复现包根目录执行 `python scripts/refit_eos.py` 可重运行。本次使用的环境为 Python 3.12.14、NumPy 2.5.3、SciPy 1.18.1。
