# E4 symmetry and Law 7 recomputation from crystal coordinates

[English](README.md) | [简体中文](README_zh.md)

**Recomputing symmetry from all 520 published structure files reproduced the published space-group numbers and site fractions for all 260 structure pairs.** The per-structure comparison found no differences. This analysis reran symmetry calculations; the DFT-relaxed coordinates came from the authors, and no new DFT calculation was performed.

| Quantity | Published result | Recomputed from coordinates |
|---|---:|---:|
| Structure pairs | 260 | 260 |
| Generated structures passing Law 7 | 61 | 61 |
| DFT-relaxed structures passing Law 7 | 113 | 113 |
| Fail-to-pass transitions after relaxation | 52 | 52 |
| Pass-to-fail transitions after relaxation | 0 | 0 |
| Median site fraction before relaxation | 1.00 | 1.00 |
| Median site fraction after relaxation | 0.75 | 0.75 |

The post-relaxation pass fractions also agree for all three roles: control 0.4167, priority 0.5786, and screened 0.1167. The complete distribution of space groups after relaxation agrees as well.

## Data and methods

- Source: AI4QC/PRIS, commit `34e6c86c083759dc1ee594ae22238ea9b5ebd8f4`.
- Generated structures: `dft/E4_design/tasks/E4-candidate_*/POSCAR.init`; relaxed structures: `outputs/20260828_dft_supplementary_structures/structures/*.cif`.
- All 260 pairs in the published supplementary index were included without selecting on results. E4 originally selected 261 candidates; `candidate_0248` has no corresponding published relaxed CIF.
- An independent script reads the coordinates and uses pymatgen / spglib to determine symmetry-equivalent site orbits. Law 7 is `number of distinct site orbits / number of atoms in the input cell <= 2/3`, with a spatial tolerance of 0.01 Å and pymatgen's default angular tolerance of 5°.
- Every structure's SHA256 hash was verified before calculation. The published numerical index and SUMMARY were used for comparison only after feature calculation was complete.
- Environment: pymatgen 2026.5.4, spglib 2.7.0, NumPy 2.5.3. No calculation errors occurred.

## Cell-convention sensitivity

The published SUMMARY was generated by `src/dft_supplementary_data.py`, which **uses the input cell directly**. A separate function, `dft/analyze.py:spacegroup_and_economy`, first obtains a standardized primitive cell. These are different conventions.

An additional run using standardized primitive cells produced 66→110 passes, with 44 fail-to-pass transitions and no pass-to-fail transitions. Relative to the input-cell convention, Law 7 verdicts changed for nine generated structures and three relaxed structures. This operation includes coordinate symmetrization within tolerance, so its results are reported separately as a sensitivity analysis and do not replace the paper's input-cell convention.

Together with the ideal-NaCl controls in `results/core_validation`, these results show why subsequent work should specify the cell representation and standardization procedure: the original implementation assigns different Law 7 / PSS values to some equivalent cells. No thresholds were changed, and the standardized-cell results did not overwrite results obtained with the authors' convention.

## Files

- `recomputed_symmetry.csv`: 260 rows of per-structure results for both input-cell and standardized-primitive-cell conventions.
- `summary.json`: aggregate results, comparisons against each published result, package versions, and calculation time.
- `standardization_verdict_changes.csv`: the 12 records whose verdicts change after standardization, with space groups, atom counts, and site fractions.
- `run.log`: execution log.
- `../../data/symmetry/provenance.json`: source paths and SHA256 hashes for every structure; the same directory contains all 520 structure files.
- `../../scripts/recompute_symmetry.py`: independent, portable recomputation script.

Run from the reproduction bundle root:

```powershell
python -X utf8 scripts/recompute_symmetry.py
```
