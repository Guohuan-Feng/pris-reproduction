# Data attribution

The prepared MP records derive from the Materials Project files distributed
with [Matbench Discovery v38](https://doi.org/10.6084/m9.figshare.22715158.v38),
released under Creative Commons Attribution 4.0 (CC BY 4.0). This experiment
selected records, excluded previously used chemical systems, calculated
composition/geometry descriptors and created grouped splits. It did not create
new DFT energies. The exact source URLs, SHA256 hashes and transformations
are recorded in `data/dataset_manifest.json` and `data_prepare.py`.

The data license and required source attribution apply independently of the
repository's code license. [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

本实验数据衍生自上述公开 MP 数据文件，保留来源与许可信息。转换包括选择、
去除既往使用的化学体系、特征计算与划分；原始能量来源于公开 DFT 记录。
